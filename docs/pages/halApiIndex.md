# Wi-Fi HAL API Index

Return to the [developer specification](halSpec.md). This index covers 476 distinct function names declared in the checked-in headers. Names repeated across headers appear once below; this deduplication does **not** imply signature equivalence or identical support. Conditional declarations are included, not asserted to exist in every build.

Use the linked header for each function's signature, argument directions, data structures, capacities, units, return values, execution annotations, side effects, and feature guards. A symbol inventory is not proof of runtime support. Callback typedefs and macros are documented in the same headers but are not callable function declarations.
